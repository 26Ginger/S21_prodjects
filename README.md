# Matrix Library in C

Реализация математической библиотеки для операций с матрицами на чистом C и демо-визуализация "Матрицы" в терминале.

## Описание проекта

Библиотека предоставляет функционал для создания, управления и выполнения математических операций с матрицами.  
Реализованы все основные матричные операции, которые могут потребоваться в вычислительной математике и машинном обучении.

## Основные функции

### Создание и удаление матриц
- `s21_create_matrix()` - создание матрицы
- `s21_remove_matrix()` - очистка и удаление матрицы

### Базовые операции
- `s21_eq_matrix()` - сравнение матриц  
- `s21_sum_matrix()` - сложение матриц
- `s21_sub_matrix()` - вычитание матриц
- `s21_mult_number()` - умножение на скаляр
- `s21_mult_matrix()` - умножение матриц

### Продвинутые операции
- `s21_transpose()` - транспонирование
- `s21_calc_complements()` - матрица алгебраических дополнений
- `s21_determinant()` - вычисление определителя
- `s21_inverse_matrix()` - обратная матрица

## Технические особенности

- **Язык**: C11 стандарт
- **Компилятор**: gcc с флагами `-Wall -Werror -Wextra -std=c11`
- **Сборка**: Статическая библиотека `s21_matrix.a`
- **Стиль кода**: Google C Style
- **Тестирование**: Unit-тесты с покрытием >80% (Check library)
- **Точность**: До 6 знаков после запятой

## Структура матрицы

```c
typedef struct matrix_struct {
    double** matrix;
    int rows;
    int columns;
} matrix_t;
```

## Система ошибок

Операции возвращают коды результата:

- `0` - OK
- `1` - Error, некорректная матрица  
- `2` - Calculation error (несовпадение размеров и т.д.)

### Основные команды:

```bash

make test         # запуск unit-тестов
make gcov_report  # генерация HTML отчета о покрытии кода

```
