 ### Описание проекта

Библиотека предоставляет функционал для создания, управления и выполнения математических операций с матрицами.  
Реализованы все основные матричные операции, которые могут потребоваться в вычислительной математике и машинном обучении.  
Проект демонстрирует понимание структур данных, работу с динамической памятью, реализацию математических алгоритмов на языке C и практики тестирования программного обеспечения.

### Приобретенные навыки

- Разработка на языке C с соблюдением стандартов C11
- Работа с динамической памятью и сложными структурами данных
- Реализация математических алгоритмов (линейная алгебра)
- Создание тестируемого кода с покрытием >80%
- Настройка CI/CD-подобных процессов через Makefile
- Отладка и оптимизация производительности

#### 🎯 Ключевые компетенции

- **Системное программирование**: Работа с памятью, указателями, структурами
- **Математическая база**: Понимание линейной алгебры и численных методов  
- **Инженерные практики**: Тестирование, документирование, стилизация кода
- **Автоматизация**: Настройка сборки, тестирования, анализа кода
