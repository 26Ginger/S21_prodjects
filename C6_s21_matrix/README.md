О проекте:
Реализация математической библиотеки для операций с матрицами на чистом C + демо-визуализация "Матрицы" в терминале.

Технологии и инструменты:

Язык C (стандарт C11), компилятор GCC

Makefile для автоматизации сборки

Библиотека Check для unit-тестов

Valgrind, AddressSanitizer для отладки памяти

LCOV/GCOV для анализа покрытия кода

Clang-format для стилизации кода

ANSI escape-коды для терминальной графики

Чему научился:

Работа с динамической памятью и структурами данных в C

Реализация сложных математических алгоритмов (детерминант, обратная матрица)

Создание статических библиотек и система ошибок

Написание комплексных unit-тестов с покрытием >80%

Отладка памяти и оптимизация кода

Профессиональная настройка инструментов сборки и тестирования

Работа с терминальной графикой через escape-коды

Создание анимаций и визуальных эффектов в консоли

Генерация псевдослучайных последовательностей

Управление временем и задержками в реальном времени

Бонус: Создал визуальный эффект "Матрицы" с падающими символами, демонстрирующий креативное применение C за пределами математических вычислений.
